# Python Classes – OOP Foundations

This project focuses on building a strong foundation in Object-Oriented Programming (OOP) using Python.

## Overview

The goal of this project was to understand how classes are designed and structured, and how object-oriented principles improve code organization and maintainability.

The `Square` class is developed incrementally across multiple tasks, introducing:

- Class definition
- Private attributes
- Property decorators (getters/setters)
- Input validation
- Area calculation methods
- Encapsulation principles

Each step enhances the class implementation to demonstrate structured and progressive OOP development.

## Files

- 0-square.py – Basic empty class definition.

## Concepts Practiced

- Encapsulation
- Data validation
- Clean class architecture
- Incremental software development
- Pythonic OOP practices
